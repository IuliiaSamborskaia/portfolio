Проект выполнен в рамках студенческой исследовательской работы.
Проведён анализ многолетних данных мониторинга качества воды по 5 станциям за период с 1980 по 2024 год.
1. Очистка и агрегация данных.
2. Анализ пропусков.
3. Корреляционный анализ для выявления взаимосвязей между показателями.
4. Исследование изменения среднегодовой температуры.
5. Исследование распределений ключевых параметров.

Ключевые выводы:
Анализ гидрохимических данных Байкала (1980–2024) показал, что сезонная изменчивость расхода воды является основным фактором, влияющим на концентрацию Mg, Ca, Cl. Долгосрочных трендов температуры не обнаружено. Основные показатели (pH, БПК) стабильны, что говорит о сохранении природного состояния экосистемы. Выявлены значительные пропуски в данных (K, Na, Hg), что необходимо учитывать при дальнейшем моделировании. Также стоит обратить внимание на некорректные данные электропроводности (EC).
