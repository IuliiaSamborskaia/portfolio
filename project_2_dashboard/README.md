В данном разделе представлен двустраничный дашборд, посвященный мониторингу студенческой успеваемости. Это студенческий прооект, задумывавшийся как протитип инструмента для студентов и преподавателей института, позволяющий оценивать, какие факторы влияют на успешное завершение курса. Данные взяты из открытых источников. 

  Первая вкладка посвящена мониторингу академических рисков студентов.
  В верхней части представлены ключевые агрегированные показатели: средний уровень риска по выбранной группе студентов, доля студентов с высоким риском, а также прогнозируемое значение среднего балла.
  Ниже представлена визуализация распределения студентов по уровням риска, которая показывает структуру группы -- долю студентов с низким, средним и высоким риском. 
  
  Также реализован сравнительный анализ: доля студентов с высоким риском отображается в разрезе курса обучения, института и региона. Для более детального анализа предусмотрена система фильтров, пользователь может выбирать институт, курс, программу, а также учебную группу. Предмет задается как базовый фильтр.

  Вторая вкладка дашборда посвящена анализу взаимосвязи вовлечённости студентов и их итоговых результатов. В верхней части представлено распределение итоговых результатов по курсу, которое показывает структуру успеваемости -- долю успешно завершивших обучение, не сдавших и отчисленных студентов.
  Ключевым элементом вкладки является точечная диаграмма, отражающая зависимость итогового балла от ранней вовлечённости студента. Это позволяет оценить влияние активности на начальных этапах обучения на итоговый результат и выявить студентов, находящихся в зоне риска.
  
  Дополнительно представлена таблица со статистикой по учебным группам. Пользователь также может выбрать конкретную образовательную программу и учебную группу.
